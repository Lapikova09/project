О проекте (2026)

ClickShop — это современная e-commerce платформа и полноценный интернет-магазин с клиент-серверной архитектурой. Приложение спроектировано на базе фреймворка Angular 17+ с использованием изолированных Standalone-компонентов и реактивного взаимодействия с бэкенд-сервером через REST API. 

Проект симулирует реальный пользовательский опыт крупного маркетплейса: от многоэтапной регистрации и гибкой фильтрации каталога до управления корзиной, работы со счетом и публикации отзывов.

Ключевые модули системы:
- Безопасность и Профиль: Авторизация на базе JWT-токенов, восстановление паролей через email-коды, мультивалютность (USD/RUB/BYN) и локализация.
- Умный каталог: Полноценный маркетплейс с поиском, многоуровневыми фильтрами категорий, ценовыми диапазонами и пагинацией данных на стороне сервера.
- Корзина и Заказы: Интерактивный менеджер корзины с подсчетом стоимости, валидацией остатков на складе и сохранением истории покупок.
- Социальный блок: Система рейтингов (визуализация звездами) и пагинируемые ветки комментариев к каждому товару.

Функциональные возможности

 Личный кабинет и сессия (`LoginComponent`)
- Безопасный вход: Авторизация по паре Email/Пароль с получением Bearer-токена.
- Регистрация: Двухэтапный процесс создания аккаунта с подтверждением через email.
- Локализация: Динамическое переключение языковых пакетов (RU/EN) и внутренних кошельков.

 Каталог и Листинг (`ListingPageComponent`)
- Фильтрация: Вложенная структура категорий (радиокнопки) и динамический слайдер цен.
- Сортировка: Ранжирование по рейтингу, новизне (дате добавления), цене и персональным предпочтениям.
- Пагинация: Постраничный контролируемый рендеринг для минимизации нагрузки на сеть.

Карточка товара и отзывы (`ItemPageComponent`)
 - UI/UX карточки: Полные технические характеристики, статус наличия, интерактивный блок добавления в корзину.
 - Отзывы: Форма отправки рецензии с выставлением оценки, сортировка комментариев по дате/рейтингу.

 Структура проекта

Архитектура проекта ориентирована на модульность и поддержку концепции единого источника правды (Single Source of Truth) через центральный сервис
